# Air-gap bundle

The reproducible offline release bundle is introduced in **Phase 5**
(`PHASE_5_AIRGAP_BUNDLE.md`).

When delivered, this directory will hold the bundle layout, an
`install.sh` for the Compose path, and the pinned-by-digest Compose
overlay. See `PROJECT_SPEC.md` Section 21.6 for the air-gap install
model.

This directory is intentionally empty in Phase 0 to reserve the path.
