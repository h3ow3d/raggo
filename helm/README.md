# Helm chart

The `raggo` Helm chart is introduced in **Phase 4** (`PHASE_4_HELM_CHART.md`).

When delivered, the chart will live at `helm/raggo/` and be published as
an OCI artifact at `oci://ghcr.io/h3ow3d/raggo/charts/raggo`. See
`PROJECT_SPEC.md` Section 21 for the full distribution model.

This directory is intentionally empty in Phase 0 to reserve the path.
