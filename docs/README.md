# Documentation

Long-form documentation lives here. Phase 0 reserves the directory; the
canonical user-facing docs in this phase remain:

- `README.md` — top-level project overview
- `PROJECT_SPEC.md` — source of truth for product requirements
- `PHASE_0_FOUNDATIONS.md` … `PHASE_8_OPERATIONS.md` — phased delivery plan
- `AGENTS.md` — guidance for AI coding agents working in this repo

Later phases (CI, Helm, air-gap, operations) will add focused docs here
as they are introduced.
